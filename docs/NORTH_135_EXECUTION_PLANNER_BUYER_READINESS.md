## How a Buyer Would Use It — Source-Supported Example

The actual Start Here source documents a use flow designed to take under ten minutes:

1. Read the two-week intention.
2. Name a Big Thing with a visible definition of done.
3. Add no more than three Medium Tasks.
4. Add up to five Small Wins.
5. Reserve one realistic focus block.
6. Identify a likely obstacle and a smallest useful response.
7. Mark what happened and leave a clearer starting point for tomorrow.

This is a self-guided planning example, not a performance promise or a therapeutic protocol.
