# NORTH Phase 2C — Scope Boundary Record

> **Candidate type:** Private static release candidate. This is not a production deployment or a public-launch authorization.

## Included

The candidate includes a premium public NORTH landing page; full Library architecture for Resources, Programs, Books & Authority, and Money Education; four verified browser-local Free Tools; three public-safe Release A product overviews marked **In founder review**; a canonical 14-locale governance system; Arabic RTL layout readiness; Apache clean-route fallback; noindex staging safeguards; and manual shared-hosting handoff documentation.

## Deliberately excluded

| Excluded area | Phase 2C state |
|---|---|
| Checkout, Gumroad, payment, pricing, cart, purchase, subscription, refund flow, bundle, discount | Not built and not rendered |
| Product delivery, downloads, customer PDFs, course access, account entitlement, support workflow | Not built and not rendered |
| Email capture, waitlist, newsletter, lead collection, analytics collection beyond existing browser-local behavior | Not added |
| Public translated product assets | Not released; English is the only complete source language |
| Portuguese / Spanish product language | First future human-review queue only |
| Arabic customer language | RTL layout QA only; not product, support, legal, delivery, or checkout ready |
| Financial products, financial advice, lending, investment, tax, credit, debt, legal or insurance guidance | Not built; Money Education remains general future architecture only |
| Books, book covers, preorders, audiobook, affiliates, physical goods, recommendations | Not built or listed as products |
| Mobile app changes | Not made |
| Vercel, Namecheap, DNS, nameservers, redirects, hosting configuration, public launch | Not changed |
| Private founder-review content, editable sources, print-review exports, internal registry, credentials | Excluded from the public static release candidate |

## Release controls retained

The App Store and verified Free Tools are the only active public actions. Each Release A overview is overview-only and contains no sale or delivery control. Each product carries six separate language-readiness fields. The static candidate is noindex by default. Any removal of these safeguards requires a separate founder-approved phase.
