# NORTH Phase 2C Dependency Register — Release A

> **Internal planning only.** Phase 2B does not authorize commerce, product publication, payment, or customer delivery.

## Release order

The appropriate next sequence is not “turn on checkout.” Each product must first pass content approval, final editable layout production, accessibility and print QA, visual/rights approval, support and policy review, delivery design, and only then a separately approved merchant / commerce review.

| Dependency | Owner | 1-3-5 Execution Planner | Decision Clarity Toolkit | Focus Recovery Program | Cannot be bypassed by |
|---|---|---|---|---|---|
| Founder content approval | Founder | Required | Required | Required | A draft marked 100% written |
| Final layout source | Founder + designer | Required | Required | Required | HTML review export |
| US Letter / A4 physical proof | Designer + founder | Required | Required | Required | Page-count check alone |
| Accessible PDF / form QA | Accessibility reviewer | Required if final digital file is interactive | Required if final digital file is interactive | Required if final digital file is interactive | Source headings alone |
| Claim / boundary review | Founder + policy reviewer | Productivity-outcome boundary | Professional-advice boundary | Non-clinical / wellbeing boundary | Internal disclaimer alone |
| Art / cover rights review | Founder + rights owner | Required if cover/art added | Required if cover/art added | Required if cover/art added | Typography draft |
| Delivery experience design | Product operations | Required | Required | Required | A public link or file upload |
| Support and refund policy | Founder + support owner | Required | Required | Required | Generic contact email |
| Merchant and tax posture | Founder + legal/accounting review | Required | Required | Required | A proposed price |
| Locale readiness | Founder + human localization reviewers | English only in initial release | English only in initial release | English only in initial release | Auto-translation |
| Founder release decision | Founder | Required | Required | Required | Any individual checklist completion |

## Product-specific non-negotiables

| Product | Non-negotiable boundary before future commercial review |
|---|---|
| 1-3-5 Execution Planner | The final product must not make productivity or performance guarantees, and final fillable / printable formats must both be tested. |
| Decision Clarity Toolkit | The final product must preserve the boundary against legal, medical, financial, investment, tax, insurance, debt, and other professional advice. |
| Focus Recovery Program | The final product must remain non-clinical and must not imply therapy, treatment, diagnosis, crisis support, burnout recovery, or health outcomes. |

## Explicitly excluded from Phase 2C unless separately approved

No Gumroad products, checkout, payments, discounts, bundles, email capture, affiliate recommendations, book productization, financial products, translations, physical-product fulfillment, mobile-app changes, Namecheap/DNS changes, Vercel changes, or public deployment should begin merely because Phase 2B draft content exists.
